# W2 — plates and carousel (n95–263, n1529–1697)

Builder W2. Scenes in `scenes/w2-plates.js`, measured tables in `motion/w2.js` (`window.MW2`, generated by `tools/w2/build_motion.py`
from the raw logs in `tools/w2/logs/`). Renders and sheets in `out/w2/`.

**Status (integrator's 2nd direction).** The motion is measured and matched (numbers below). The current layouts are a first pass and
will be re-laid out on the integrator's go. Every curve below is written so it can be re-applied to a composition of our own: what it
was measured on, the frame range, what it drives (camera or element), the pivot and the units. The tables are all in `motion/w2.js`;
the compact copies here are the same numbers.

Units everywhere: px are 1080-wide frame px (×1.778 for the 1920 render); frames n are reference frames at 30 fps; "zoom %/f" is the
per-frame scale change; "centre drift" is how far the picture point under the frame centre (540, 304) moves on screen in that frame
(+x right, +y down). Blur σ is a Gaussian standard deviation in on-screen px.

## INTEGRATOR

- `INTEGRATOR: lib/art.js cover()` gives every cover gradient an id derived from its seed, so two scenes that draw the same cover
  (W2, W6 both use `hush()`) share ids; a `url(#id)` can resolve into a `display:none` scene and paint nothing. I rename every id in my
  scenes after build (`uniquify()` in `scenes/w2-plates.js`). Suggest appending a global counter to the id in art.js.

  same seek contract. Also: for an `<img>`, `_seekTo` resolves at once, so the first capture can catch a half-decoded image; I await
